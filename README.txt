WorldStore - GitHub Pages version

This package is ready for GitHub Pages and custom domain worldstore.store.
CNAME is already included.

Important: GitHub Pages is static hosting. The current checkout/admin code in this package is browser-local and does NOT provide a shared server database or email order system. For a real shared admin/orders backend, deploy the Node.js/PHP backend on a server or connect a hosted database/service.

Custom domain DNS for Namecheap:
A @ -> 185.199.108.153
A @ -> 185.199.109.153
A @ -> 185.199.110.153
A @ -> 185.199.111.153
CNAME www -> YOUR_GITHUB_USERNAME.github.io

Then GitHub repository Settings -> Pages -> Custom domain -> worldstore.store -> Save.
